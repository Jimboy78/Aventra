# Frontend - Aventra

El frontend de Aventra es una aplicación web desarrollada con Next.js 15, React 19 y TailwindCSS que permite a los usuarios crear y jugar historias interactivas generadas por IA.

## 🚀 Características

- **Configuración de Personaje y Mundo**: Interfaz intuitiva para crear personajes y definir el mundo de juego
- **Juego Narrativo Interactivo**: Interfaz de chat para interactuar con la IA y tomar decisiones
- **Consulta de Estado**: Paneles para ver información del personaje, inventario, bestiario, misiones y diario
- **Soporte de Imágenes**: Visualización de imágenes generadas por IA en formato Base64
- **Modo Debug**: Panel avanzado para desarrolladores (opcional)
- **UI Responsive**: Diseño adaptable para desktop y móviles
- **Modo Oscuro**: Soporte automático para tema oscuro/claro

## 🛠️ Tecnologías

- **Framework**: Next.js 15 con App Router
- **UI**: React 19 con TypeScript
- **Estilos**: TailwindCSS 4
- **Markdown**: react-markdown para renderizar narrativa
- **HTTP Client**: Fetch API nativo
- **Build Tool**: Turbopack
